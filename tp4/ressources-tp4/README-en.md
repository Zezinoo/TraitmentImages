# Lab 4 resources

Resources for the six Lab 4 activities.

| File | Origin and preparation |
|---|---|
| `01-bandes-verticales-32.png` | Teaching test pattern, 256 rows by 256 columns, intensity `0.5 + 0.4*cos(2*pi*x/32)`. |
| `02-bandes-verticales-16.png` | Same construction with a 16-pixel period along columns. |
| `03-bandes-horizontales-16.png` | Same construction with a 16-pixel period along rows. |
| `04-facade-reference.png` | Unmodified copy of `tp3/ressources/02-facade-reference.png`. |
| `05-rectangle.png` | Teaching image, 256 rows by 256 columns, background level 0.2 and rectangle level 0.8 on rows 70 to 129 and columns 60 to 149. |
| `06-facade-periodique.png` | Teaching perturbation added to the reference facade: `0.08*cos(2*pi*32*x/512)`, then rounded to 8 bits. |
| `07-circuit-reference.png` | Derived from the Lab 3 circuit image `05-circuit-reference.png`, itself from the course historical image collection. The image is transformed with `0.15 + 0.7 * image` and rounded to 8 bits. |
| `08-circuit-periodique.png` | Image 07 with `0.06*cos(2*pi*(x+y)/32) + 0.06*cos(2*pi*y/16)` added, then rounded to 8 bits. |

The test patterns are teaching materials for this lab and are stored as 8-bit images after rounding. Quantization can introduce weak harmonics; the main peaks correspond to the stated frequencies. Scripts read the pixel codes and divide by 255, without min-max rescaling.

The facade image comes from the course historical image collection through Labs 2 and 3. Its original author and license are not documented in the available files; no additional license is assigned here. The facade is a reference for numerical experiments and has no calibrated physical unit. The preparation script checks that values remain in [0, 1] before saving and does not apply clipping.

The circuit image is 512 rows by 512 columns with no resizing. The periodic disturbances are written to preserve the required intensity range without clipping. All files are generated by `practical-work/scripts/prepare_tp4_resources.py`; no internet connection or image generation is required during the lab.
