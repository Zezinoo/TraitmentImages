# Lab 4: installing the resources and scripts

1. Extract the archive, then copy the `tp4/` and `ressources-tp4/` folders into your existing `traitement-images/` project.
2. Open the project in Visual Studio Code and select the interpreter from your `.venv` environment.
3. Follow the English PDF. Script and image filenames are the same in both language versions; the scripts are provided in French.
4. Run the scripts with **Run Python File**. Close each figure window to let the script continue. Figures are saved in `tp4/resultats/`.

The virtual environment was created in Lab 1. If a dependency is missing, activate that environment and run:

```text
python -m pip install -r ressources-tp4/requirements.txt
```

The image origins and preparation steps are listed in `ressources-tp4/README-en.md`.
