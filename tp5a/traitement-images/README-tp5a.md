# TP5A : installation des ressources et des scripts

1. Extrayez l'archive, puis copiez les dossiers `tp5a/` et `ressources-tp5a/` dans votre projet `traitement-images/` déjà utilisé pour les TP précédents.
2. Ouvrez ce projet dans Visual Studio Code et sélectionnez l'interpréteur de votre environnement `.venv`.
3. Utilisez les scripts français et suivez le sujet PDF et complétez les passages `TODO` des scripts indiqués.
4. Utilisez **Run Python File**. Fermez la fenêtre d'une figure pour poursuivre le script. Les résultats sont enregistrés dans `tp5a/resultats/`.

L'environnement virtuel est déjà créé. Si une dépendance manque, activez cet environnement et installez les paquets indiqués :

```text
python -m pip install -r ressources-tp5a/requirements.txt
```

Les provenances et les traitements des images sont précisés dans `ressources-tp5a/README.md`.
