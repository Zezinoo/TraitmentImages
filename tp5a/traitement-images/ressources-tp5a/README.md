# Ressources du TP5a

Les images du TP sont générées de façon déterministe par `tp5a_outils.py` à partir de formes géométriques et d'un bruit pseudo-aléatoire à graine fixe. Elles n'utilisent pas de photographie tierce. Les scènes comportent une référence exacte, ce qui permet de comparer le masque à la vérité terrain ; cette référence ne simule pas toutes les difficultés d'une acquisition réelle.

Le pas spatial de la scène de mesure est une donnée pédagogique fixée à 0,40 µm/pixel. Il ne doit pas être interprété comme l'étalonnage d'une caméra réelle.
