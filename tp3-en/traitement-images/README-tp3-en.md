# TP3: installing resources and scripts

1. Extract the archive, then copy `tp3/` and `ressources-tp3/` into your existing `traitement-images/` project.
2. Open the project in Visual Studio Code and select the interpreter from your `.venv` environment.
3. Follow the English PDF and complete the `TODO` sections in the indicated scripts. This archive contains English scripts; use the English subject.
4. Use **Run Python File**. Close each figure window to let the script continue. Results are saved in `tp3/resultats/`.

Keep the folder and image filenames unchanged. If a dependency is missing, activate your existing virtual environment and run:

```text
python -m pip install -r ressources-tp3/requirements.txt
```

Image sources and preparation steps are listed in `ressources-tp3/README-en.md`.
